# Keyboard Controls – Freedom Force: The Reckoning

## Movement
| Key       | Action                   |
|-----------|--------------------------|
| `A`       | Move left                |
| `D`       | Move right               |
| `Space`   | Jump                     |

## Combat
| Key       | Action                              |
|-----------|-------------------------------------|
| `L`       | Fire red laser (damages enemies and boss) |

## Special / Abilities
| Key       | Action                                                          |
|-----------|-----------------------------------------------------------------|
| `O`       | Activate anti-bomb shield (during boss nuclear attack window)   |
| `1`       | Deploy B2 Bomb – destroys **all** enemies in current stage     |
| `2`       | Deploy Arrow Bomb – destroys enemies within 3-tile radius      |
| `3`       | Deploy Halo Bomb – destroys half the ground layer              |

## System
| Key       | Action                            |
|-----------|-----------------------------------|
| `P`       | Pause / Resume                    |
| `R`       | Restart (only on Game Over screen)|
| `Enter`   | Start game (title screen)         |

---

## Notes

- **Anti-bomb shield (O)** consumes one anti-bomb item per use.  
  Collect glowing red/yellow anti-bomb orbs across stages 1–5 (6 total: 1 per stage, 2 in stage 5).  
  You need at least **5** to survive all 5 nuclear attacks in the boss fight.

- **B2 Bomb** is limited to **3 total** across the whole game.  
- **Arrow Bomb** has **20 total** across stages 1–5.  
- **Halo Bomb** has **2 total** across the whole game.

- The trump transformation (triggered by collecting a golden orb) lasts **20 seconds** and grants immunity to enemy touch. It is **not** activated by a key – it activates on pickup.
