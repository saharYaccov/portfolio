# 🎮 מקשי השליטה — AI Snake Game

## ניווט ובקרת משחק

| מקש | פעולה |
|------|--------|
| `Q` / `Esc` | יציאה מהמשחק |
| `R` | אתחול מחדש (חזרה לשלב 1, שמירת המודל) |
| `Space` | מעבר לשלב הבא לאחר השלמת שלב |
| `M` | החלפת מצב בהירות (כהה / בהיר) |
| לחיצת עכבר | לחצן הבהירות בפינה הימנית של ה-HUD |

## כיוון הנחש — דריסת פינות (override)

| מקש | פינה |
|------|------|
| `A` | שמאל למעלה |
| `Z` | שמאל למטה |
| `L` | ימין למעלה |
| `.` | ימין למטה |

## שליטה במודל הבינה מלאכותית

| מקש | פעולה |
|------|--------|
| `+` / `=` | הגדלת עומק עץ ההחלטה ב-1 ואימון מחדש |
| `-` | הקטנת עומק עץ ההחלטה ב-1 ואימון מחדש |
| `T` | הגדלת מספר הפיצרים הפעילים ב-1 (לפי סדר חשיבות: p-value + קורלציה) ואימון מחדש |
| `Y` | הקטנת מספר הפיצרים הפעילים ב-1 (לפי סדר חשיבות) ואימון מחדש |

### 🧬 הסבר פיצרים (T/Y)

הפיצרים ממוינים לפי **ציון חשיבות משולב**:
1. **קורלציית פירסון** (|r|) בין הפיצר לתוויות התנועה
2. **שונות בין-מחלקתית** של ממוצעי הפיצר לפי כיוון

לחיצת `T` מוסיפה את הפיצר הכי חשוב הבא שעדיין לא פעיל.
לחיצת `Y` מסירה את הפיצר הכי פחות חשוב שפעיל.
טווח אפשרי: 1–15 פיצרים פעילים (ברירת מחדל: 15).

## פיצרים זמינים (15 סה"כ)

| שם פיצר | תיאור |
|---------|--------|
| `danger_up` | האם יש מכשול ישיר מעל |
| `danger_down` | האם יש מכשול ישיר מתחת |
| `danger_left` | האם יש מכשול ישיר שמאלה |
| `danger_right` | האם יש מכשול ישיר ימינה |
| `food_row_sign` | כיוון האוכל אנכית (-1/0/1) |
| `food_col_sign` | כיוון האוכל אופקית (-1/0/1) |
| `snake_len_norm` | אורך הנחש מנורמל לפי גודל הלוח |
| `dir_up` | האם הכיוון הנוכחי הוא למעלה |
| `dir_down` | האם הכיוון הנוכחי הוא למטה |
| `dir_left` | האם הכיוון הנוכחי הוא שמאלה |
| `dir_right` | האם הכיוון הנוכחי הוא ימינה |
| `space_up_norm` | מרחב פנוי מעל (flood-fill מנורמל) |
| `space_down_norm` | מרחב פנוי מתחת |
| `space_left_norm` | מרחב פנוי שמאלה |
