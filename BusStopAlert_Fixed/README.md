# מחשבון מרחק לתחנת אוטובוס 📍

אפליקציה לחישוב מרחק בין המיקום הנוכחי שלך לבין תחנת אוטובוס שתבחר.

## תכונות ✨

- 🌍 איתור אוטומטי של המיקום הנוכחי שלך
- 📏 חישוב מרחק מדויק באמצעות נוסחת Haversine
- 🗺️ הצגת מפה אינטראקטיבית עם סימון שני המיקומים
- ⏱️ הערכת זמן הליכה
- 🎨 עיצוב מודרני ומרשים
- 📱 תמיכה מלאה במובייל

## טכנולוגיות 🛠️

- **HTML5** - מבנה הדף
- **CSS3** - עיצוב מתקדם עם אנימציות
- **JavaScript (Vanilla)** - לוגיקה ואינטראקציות
- **Leaflet.js** - ספריית מפות קוד פתוח
- **OpenStreetMap** - מקור המפות (ללא צורך ב-API key)
- **Geolocation API** - מובנה בדפדפן

## התקנה והרצה 🚀

### שיטה 1: GitHub Pages (מומלץ)

1. צור repository חדש ב-GitHub
2. העלה את הקבצים הבאים:
   - `index.html`
   - `styles.css`
   - `script.js`
3. עבור להגדרות ה-repository
4. בחר ב-"Pages" מהתפריט הצדי
5. בחר ב-branch "main" ולחץ "Save"
6. האתר שלך יהיה זמין בכתובת:
   `https://[שם-המשתמש].github.io/[שם-הrepository]`

### שיטה 2: הרצה מקומית

1. פתח את הקובץ `index.html` בדפדפן
2. או השתמש בשרת מקומי:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (עם npx)
   npx serve
   ```

## שימוש 📖

1. **פתח את האפליקציה** - הדפדפן יבקש הרשאה לגישה למיקום
2. **אשר גישה למיקום** - חיוני לתפקוד האפליקציה
3. **הזן קואורדינטות** של תחנת האוטובוס:
   - קו רוחב (Latitude): מספר בין -90 ל-90
   - קו אורך (Longitude): מספר בין -180 ל-180
4. **לחץ "חשב מרחק"**
5. **צפה בתוצאות**:
   - המרחק המדויק
   - זמן הליכה משוער
   - מפה עם קו המסלול

### דוגמה - תחנה מרכזית חיפה

אם אתה בחיפה, נסה:
- קו רוחב: `32.8154`
- קו אורך: `34.9946`

או הקלד בקונסול הדפדפן:
```javascript
useHaifaExample()
```

## איך לקבל קואורדינטות? 🗺️

### Google Maps
1. פתח את Google Maps
2. לחץ לחיצה ימנית על המיקום הרצוי
3. לחץ על הקואורדינטות כדי להעתיק

### OpenStreetMap
1. עבור ל-[openstreetmap.org](https://www.openstreetmap.org)
2. מצא את המיקום
3. לחץ לחיצה ימנית -> "Show address"
4. הקואורדינטות יופיעו בתיבה

## שאלות ותשובות ❓

### האם צריך שרת?
**לא!** האפליקציה סטטית לחלוטין ורצה ישירות בדפדפן.

### האם צריך API key?
**לא!** משתמשים ב-OpenStreetMap שהוא חינמי לגמרי.

### האם עובד אופליין?
לא, דרושה חיבור לאינטרנט כדי לטעון את המפות.

### האם המיקום שלי נשמר?
**לא!** המיקום נשאר רק בדפדפן ולא נשלח לשום מקום.

### למה הדפדפן מבקש הרשאה למיקום?
זה חלק מתקן הביטחון של הדפדפן - אף אתר לא יכול לגשת למיקום בלי הרשאה מפורשת.
